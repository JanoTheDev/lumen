# Adobe Premiere shortcuts (Windows, default keyboard layout)

Many commands only work when the right panel has focus. On macOS, Ctrl becomes Cmd and Alt becomes Option.

| Action                                  | Shortcut           | Mode/context              |
| --------------------------------------- | ------------------ | ------------------------- |
| New project                             | Ctrl+Alt+N         | Any                       |
| Open project                            | Ctrl+O             | Any                       |
| Save project                            | Ctrl+S             | Any                       |
| Save as                                 | Ctrl+Shift+S       | Any                       |
| Import media                            | Ctrl+I             | Any                       |
| Export (open Export mode)               | Ctrl+M             | Sequence or clip selected |
| Undo                                    | Ctrl+Z             | Any                       |
| Redo                                    | Ctrl+Shift+Z       | Any                       |
| Keyboard Shortcuts editor               | Ctrl+Alt+K         | Any                       |
| Selection tool                          | V                  | Timeline, Program Monitor |
| Track Select Forward tool               | A                  | Timeline                  |
| Ripple Edit tool                        | B                  | Timeline                  |
| Rolling Edit tool                       | N                  | Timeline                  |
| Razor tool                              | C                  | Timeline                  |
| Slip tool                               | Y                  | Timeline                  |
| Slide tool                              | U                  | Timeline                  |
| Pen tool                                | P                  | Timeline, Program Monitor |
| Hand tool                               | H                  | Timeline, monitors        |
| Zoom tool                               | Z                  | Timeline, monitors        |
| Type tool                               | T                  | Program Monitor           |
| Play / stop                             | Space              | Timeline, monitors        |
| Play backward / stop / play forward     | J / K / L          | Timeline, monitors        |
| Previous / next frame                   | Left / Right arrow | Timeline, monitors        |
| Previous / next edit point              | Up / Down arrow    | Timeline                  |
| Go to start / end of sequence           | Home / End         | Timeline                  |
| Mark in / mark out                      | I / O              | Timeline, monitors        |
| Clear in and out                        | Ctrl+Shift+X       | Timeline, monitors        |
| Insert from Source Monitor              | ,                  | Source Monitor            |
| Overwrite from Source Monitor           | .                  | Source Monitor            |
| Lift (leave gap)                        | ;                  | Timeline with in and out  |
| Extract (close gap)                     | '                  | Timeline with in and out  |
| Add edit at playhead                    | Ctrl+K             | Timeline, targeted tracks |
| Add edit to all tracks                  | Ctrl+Shift+K       | Timeline                  |
| Delete, leave a gap                     | Delete             | Timeline selection        |
| Ripple delete, close the gap            | Shift+Delete       | Timeline selection        |
| Ripple trim previous edit to playhead   | Q                  | Timeline                  |
| Ripple trim next edit to playhead       | W                  | Timeline                  |
| Toggle snapping                         | S                  | Timeline                  |
| Link / unlink audio and video           | Ctrl+L             | Timeline selection        |
| Match frame                             | F                  | Timeline                  |
| Apply default transitions to selection  | Shift+D            | Timeline selection        |
| Apply default video transition          | Ctrl+D             | Edit point                |
| Apply default audio transition          | Ctrl+Shift+D       | Edit point                |
| Audio Gain                              | G                  | Selected clip             |
| Speed/Duration                          | Ctrl+R             | Selected clip             |
| Zoom timeline in / out                  | = / -              | Timeline                  |
| Zoom to whole sequence                  | Backslash          | Timeline                  |
| Render effects in to out                | Enter              | Timeline                  |
| Maximize or restore panel under pointer | Grave accent key   | Any panel                 |
| Full-screen video                       | Ctrl+grave accent  | Program Monitor           |
