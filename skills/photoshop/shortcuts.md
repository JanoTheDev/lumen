# Photoshop shortcuts (Windows, default set)

| Action                                          | Shortcut                | Mode/context             |
| ----------------------------------------------- | ----------------------- | ------------------------ |
| New document                                    | Ctrl+N                  | Any                      |
| Open                                            | Ctrl+O                  | Any                      |
| Save                                            | Ctrl+S                  | Any                      |
| Save As                                         | Ctrl+Shift+S            | Any                      |
| Export As                                       | Ctrl+Alt+Shift+W        | Any                      |
| Close document                                  | Ctrl+W                  | Any                      |
| Undo                                            | Ctrl+Z                  | Any                      |
| Redo                                            | Ctrl+Shift+Z            | Any                      |
| Step backward                                   | Ctrl+Alt+Z              | Any                      |
| Image Size                                      | Ctrl+Alt+I              | Any                      |
| Canvas Size                                     | Ctrl+Alt+C              | Any                      |
| Free Transform                                  | Ctrl+T                  | Layer or selection       |
| Commit crop or transform                        | Enter                   | Crop or transform active |
| Cancel crop or transform                        | Esc                     | Crop or transform active |
| Move tool                                       | V                       | Tools                    |
| Rectangular / Elliptical Marquee                | M                       | Tools                    |
| Lasso tools                                     | L                       | Tools                    |
| Object Selection / Quick Selection / Magic Wand | W                       | Tools                    |
| Crop tool                                       | C                       | Tools                    |
| Eyedropper                                      | I                       | Tools                    |
| Spot Healing / Healing Brush                    | J                       | Tools                    |
| Brush tool                                      | B                       | Tools                    |
| Clone Stamp                                     | S                       | Tools                    |
| Eraser                                          | E                       | Tools                    |
| Gradient / Paint Bucket                         | G                       | Tools                    |
| Type tool                                       | T                       | Tools                    |
| Pen tool                                        | P                       | Tools                    |
| Hand tool                                       | H, or hold Space        | Canvas                   |
| Zoom tool                                       | Z                       | Tools                    |
| Cycle tools in a group                          | Shift plus the tool key | Tools                    |
| Smaller / larger brush                          | [ / ]                   | Painting tools           |
| Default colors (black and white)                | D                       | Any                      |
| Swap foreground and background                  | X                       | Any                      |
| Quick Mask mode                                 | Q                       | Selection                |
| Zoom in / out                                   | Ctrl+= / Ctrl+-         | Canvas                   |
| Fit on screen                                   | Ctrl+0                  | Canvas                   |
| 100 percent view                                | Ctrl+1                  | Canvas                   |
| Select all                                      | Ctrl+A                  | Any                      |
| Deselect                                        | Ctrl+D                  | Selection                |
| Reselect                                        | Ctrl+Shift+D            | Any                      |
| Inverse selection                               | Ctrl+Shift+I            | Selection                |
| Feather selection                               | Shift+F6                | Selection                |
| New layer (with dialog)                         | Ctrl+Shift+N            | Any                      |
| Duplicate layer or copy selection to new layer  | Ctrl+J                  | Layer                    |
| Group layers                                    | Ctrl+G                  | Layers selected          |
| Merge down                                      | Ctrl+E                  | Layer                    |
| Clipping mask                                   | Ctrl+Alt+G              | Layer                    |
| Show / hide Layers panel                        | F7                      | Any                      |
| Fill with foreground color                      | Alt+Backspace           | Layer or selection       |
| Fill with background color                      | Ctrl+Backspace          | Layer or selection       |
| Levels                                          | Ctrl+L                  | Pixel layer              |
| Curves                                          | Ctrl+M                  | Pixel layer              |
| Hue/Saturation                                  | Ctrl+U                  | Pixel layer              |
| Desaturate                                      | Ctrl+Shift+U            | Pixel layer              |
| Show / hide all panels                          | Tab                     | Any                      |
| Toggle rulers                                   | Ctrl+R                  | Canvas                   |
| Keyboard Shortcuts editor                       | Ctrl+Alt+Shift+K        | Any                      |

Brightness/Contrast has no default shortcut: Image > Adjustments > Brightness/Contrast, or Layer > New Adjustment Layer > Brightness/Contrast.
