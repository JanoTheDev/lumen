# Blender shortcuts (default keymap)

Viewport shortcuts work when the mouse pointer is over the 3D Viewport. "Numpad" means the numeric keypad, not the number row.

## Global

| Action                         | Shortcut     | Mode/context           |
| ------------------------------ | ------------ | ---------------------- |
| Menu Search (find any command) | F3           | Any editor             |
| Undo                           | Ctrl+Z       | Any                    |
| Redo                           | Ctrl+Shift+Z | Any                    |
| Adjust Last Operation panel    | F9           | After an operation     |
| Repeat last                    | Shift+R      | Any                    |
| Save file                      | Ctrl+S       | Any                    |
| Save As                        | Ctrl+Shift+S | Any                    |
| Open file                      | Ctrl+O       | Any                    |
| New file                       | Ctrl+N       | Any                    |
| Render image                   | F12          | Any                    |
| Render animation               | Ctrl+F12     | Any                    |
| Show or hide last render       | F11          | Any                    |
| Toggle Maximize Area           | Ctrl+Space   | Editor under the mouse |
| Play or pause animation        | Space        | Default keymap         |
| Context menu                   | Right click  | Editor under the mouse |

| Camera view                    | Numpad 0                              | 3D Viewport  |
| Set active object as camera    | Ctrl+Numpad 0                         | Object Mode  |
| Frame All                      | Home                                  | 3D Viewport  |
| Frame Selected                 | Numpad .                              | 3D Viewport  |
| Local view (isolate selection) | Numpad /                              | 3D Viewport  |
| Zoom Region                    | Shift+B                               | 3D Viewport  |
| Toolbar                        | T                                     | 3D Viewport  |
| Sidebar                        | N                                     | 3D Viewport  |
| Shading pie menu               | Z                                     | 3D Viewport  |
