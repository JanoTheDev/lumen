# OBS Studio shortcuts

OBS ships with almost no global hotkeys. Start/Stop Recording, Start/Stop Streaming, scene switching, mute and push-to-talk are all **unassigned** until you set them in Settings, Hotkeys. The table lists the built-in keys that work in the main window, then the menu paths for common actions that have no key.

| Action                          | Shortcut              | Mode/context                                                              |
| ------------------------------- | --------------------- | ------------------------------------------------------------------------- |
| Undo                            | Ctrl+Z                | Main window (Edit menu)                                                   |
| Redo                            | Ctrl+Y                | Main window (Edit menu)                                                   |
| Copy selected source            | Ctrl+C                | Sources dock or preview                                                   |
| Paste source as reference       | Ctrl+V                | Sources dock or preview                                                   |
| Delete selected source or scene | Delete                | Sources or Scenes dock                                                    |
| Rename selected source or scene | F2                    | Sources or Scenes dock                                                    |
| Edit Transform                  | Ctrl+E                | Selected source                                                           |
| Reset Transform                 | Ctrl+R                | Selected source                                                           |
| Fit to screen                   | Ctrl+F                | Selected source                                                           |
| Stretch to screen               | Ctrl+S                | Selected source                                                           |
| Center to screen                | Ctrl+D                | Selected source                                                           |
| Nudge source one pixel          | Arrow keys            | Preview, source selected                                                  |
| Open a list item's menu         | Shift+F10 or Menu key | Scenes or Sources dock                                                    |
| Move focus between docks        | Tab / Shift+Tab       | Main window                                                               |
| Toggle fullscreen interface     | F11                   | Main window (View menu)                                                   |
| Close dialog without saving     | Esc                   | Any dialog                                                                |
| Confirm dialog                  | Enter                 | Any dialog                                                                |
| Start / Stop Recording          | unassigned            | Controls dock button; assign a key in Settings, Hotkeys                   |
| Start / Stop Streaming          | unassigned            | Controls dock button                                                      |
| Pause recording                 | unassigned            | Pause button beside Stop Recording while recording                        |
| Start Virtual Camera            | unassigned            | Controls dock button                                                      |
| Toggle Studio Mode              | unassigned            | Controls dock button                                                      |
| Switch to a scene               | unassigned            | Click the scene in the Scenes dock; per-scene hotkey in Settings, Hotkeys |
| Mute / unmute Mic/Aux           | unassigned            | Speaker icon in the Audio Mixer                                           |
| Push-to-talk                    | unassigned            | Settings, Hotkeys, Mic/Aux                                                |
| Add a source                    | none                  | Plus button under the Sources dock, or right click in the dock, Add       |
| Add a scene                     | none                  | Plus button under the Scenes dock                                         |
| Open source properties          | Double click          | Source in the Sources dock                                                |
| Open source filters             | none                  | Right click a source, Filters                                             |
| Hide / show a source            | none                  | Eye icon beside the source                                                |
| Lock a source                   | none                  | Lock icon beside the source                                               |
| Settings                        | none                  | Controls dock, Settings, or File, Settings                                |
| Recording Path / Format         | none                  | Settings, Output, Recording                                               |
| Output resolution and FPS       | none                  | Settings, Video                                                           |
| Microphone device               | none                  | Settings, Audio, Mic/Auxiliary Audio                                      |
| Hotkeys                         | none                  | Settings, Hotkeys                                                         |
| Show recordings folder          | none                  | File, Show Recordings                                                     |
| Remux MKV to MP4                | none                  | File, Remux Recordings                                                    |
| Auto-Configuration Wizard       | none                  | Tools, Auto-Configuration Wizard                                          |
| WebSocket server                | none                  | Tools, WebSocket Server Settings                                          |
| Reset docks                     | none                  | Docks, Reset Docks                                                        |
| Lock docks                      | none                  | Docks, Lock Docks                                                         |
| Profiles                        | none                  | Profile menu                                                              |
| Scene collections               | none                  | Scene Collection menu                                                     |
| Log files                       | none                  | Help, Log Files                                                           |
