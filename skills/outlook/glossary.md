# Outlook (new) glossary

- **New Outlook** — the redesigned Outlook for Windows; it looks like Outlook on the web.
- **Classic Outlook** — the older desktop Outlook with the File tab and a large ribbon.
- **Reading pane** — the right side of the window that shows the selected email.
- **Focused and Other** — two inbox tabs that split important mail from the rest.
- **Archive** — moves an email out of the Inbox into the Archive folder without deleting it.
- **Deleted Items** — where deleted email goes; it can be moved back from there.
- **Draft** — an email that is written but not sent, kept in Drafts.
- **Pop out** — opens a reply or new message in its own window.
- **Check names** — matches typed names against the address book.
- **Sweep** — removes many emails from one sender at once.
