# Outlook (new) shortcuts

From Microsoft's "Keyboard shortcuts for Outlook" page, new Outlook tab, checked 2026-10-01. Rows marked "web help" come from Outlook on the web shortcut lists and secondary sources; check them when they fail. Users can switch the shortcut set (Outlook, Gmail, Yahoo, off) in Settings > Accessibility.

| Action                           | Shortcut     | Mode/context    |
| -------------------------------- | ------------ | --------------- |
| New message                      | Ctrl+N       | Mail            |
| Reply                            | Ctrl+R       | Email selected  |
| Reply all                        | Ctrl+Shift+R | Email selected  |
| Forward                          | Ctrl+F       | Email selected  |
| Send (only after the user's yes) | Ctrl+Enter   | Compose         |
| Close a new message              | Esc          | Compose         |
| Open in a new window             | Shift+Enter  | Email selected  |
| Next message                     | Ctrl+>       | Reading         |
| Previous message                 | Ctrl+<       | Reading         |
| Mark as read                     | Ctrl+Q       | Email selected  |
| Mark as unread                   | Ctrl+U       | Email selected  |
| Flag                             | Insert       | Email selected  |
| Delete (needs the user's yes)    | Delete       | Email selected  |
| Delete for good (never use)      | Shift+Delete | Email selected  |
| Go to Mail                       | Ctrl+1       | Anywhere        |
| Search                           | Alt+Q        | Web help        |
| Archive                          | E            | Web help        |
| Check names                      | Ctrl+K       | Compose, To box |
