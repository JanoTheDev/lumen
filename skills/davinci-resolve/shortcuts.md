# DaVinci Resolve shortcuts (Windows, default keyboard set)

Single-letter keys are the same on macOS; Ctrl becomes Cmd and Alt becomes Option.

| Action                                  | Shortcut           | Mode/context                  |
| --------------------------------------- | ------------------ | ----------------------------- |
| Project Manager                         | Shift+1            | Any page                      |
| Media page                              | Shift+2            | Any page                      |
| Cut page                                | Shift+3            | Any page                      |
| Edit page                               | Shift+4            | Any page                      |
| Fusion page                             | Shift+5            | Any page                      |
| Color page                              | Shift+6            | Any page                      |
| Fairlight page                          | Shift+7            | Any page                      |
| Deliver page                            | Shift+8            | Any page                      |
| Project Settings                        | Shift+9            | Any page                      |
| Keyboard Customization                  | Ctrl+Alt+K         | Any page                      |
| Save project                            | Ctrl+S             | Any page                      |
| Undo                                    | Ctrl+Z             | Any page                      |
| Redo                                    | Ctrl+Shift+Z       | Any page                      |
| Import media                            | Ctrl+I             | Media, Cut, Edit              |
| New timeline                            | Ctrl+N             | Media Pool                    |
| New bin                                 | Ctrl+Shift+N       | Media Pool                    |
| Play / pause                            | Space              | Viewer or timeline            |
| Play backward / stop / play forward     | J / K / L          | Viewer or timeline            |
| Fast reverse / fast forward             | Shift+J / Shift+L  | Viewer or timeline            |
| Previous / next frame                   | Left / Right arrow | Viewer or timeline            |
| Previous / next edit point              | Up / Down arrow    | Timeline                      |
| Go to start / end                       | Home / End         | Timeline                      |
| Mark in / mark out                      | I / O              | Viewer or timeline            |
| Clear in / clear out                    | Alt+I / Alt+O      | Viewer or timeline            |
| Selection (normal edit) mode            | A                  | Edit page                     |
| Trim edit mode                          | T                  | Edit page                     |
| Dynamic trim mode                       | W                  | Edit page                     |
| Blade edit mode                         | B                  | Edit page                     |
| Cut all tracks at the playhead          | Ctrl+B             | Edit page timeline            |
| Toggle snapping                         | N                  | Timeline                      |
| Toggle linked selection                 | Ctrl+Shift+L       | Timeline                      |
| Delete, leave a gap                     | Backspace          | Timeline selection            |
| Ripple delete, close the gap            | Shift+Backspace    | Timeline selection            |
| Insert edit                             | F9                 | Edit page, from source viewer |
| Overwrite edit                          | F10                | Edit page, from source viewer |
| Replace edit                            | F11                | Edit page, from source viewer |
| Append to end of timeline               | Shift+F12          | Edit page, from source viewer |
| Add default transition (Cross Dissolve) | Ctrl+T             | Edit point or selected clip   |
| Match frame                             | F                  | Timeline                      |
| Zoom timeline in / out                  | Ctrl+= / Ctrl+-    | Timeline                      |
| Zoom to fit the whole timeline          | Shift+Z            | Timeline                      |
| Full-screen viewer                      | Ctrl+F             | Viewer                        |
| Change clip speed                       | R                  | Selected timeline clip        |
| Enable / disable clip                   | D                  | Selected timeline clip        |
| Add serial node                         | Alt+S              | Color page                    |
| Add parallel node                       | Alt+P              | Color page                    |
| Enable / disable current node           | Ctrl+D             | Color page                    |
| Bypass all grades and effects           | Shift+D            | Color and Edit pages          |
| Reset selected node grade               | Shift+Home         | Color page                    |
| Reset all grades and nodes              | Ctrl+Home          | Color page                    |
| Grab still to the Gallery               | Ctrl+Alt+G         | Color page                    |
| Previous / next clip                    | Up / Down arrow    | Color page                    |
