# Outlook (classic) shortcuts

From Microsoft's "Keyboard shortcuts for Outlook" page, classic Outlook tab, checked 2026-10-01. Rows marked "secondary" are common but not on that page.

| Action                           | Shortcut     | Mode/context              |
| -------------------------------- | ------------ | ------------------------- |
| New message                      | Ctrl+Shift+M | Any view                  |
| New item of the current view     | Ctrl+N       | Mail: a new message       |
| Reply                            | Ctrl+R       | Email selected            |
| Reply all                        | Ctrl+Shift+R | Email selected            |
| Forward                          | Ctrl+F       | Email selected            |
| Send (only after the user's yes) | Alt+S        | Message window            |
| Send (only after the user's yes) | Ctrl+Enter   | Message window            |
| Search                           | Ctrl+E or F3 | Mail                      |
| Open the selected email          | Ctrl+O       | Message list              |
| Next / previous email            | Down / Up    | Message list              |
| Mark as read                     | Ctrl+Q       | Email selected            |
| Mark as unread                   | Ctrl+U       | Email selected            |
| Flag for follow up               | Ctrl+Shift+G | Email selected            |
| Move to a folder                 | Ctrl+Shift+V | Email selected            |
| Delete (needs the user's yes)    | Alt+H, D     | Message list              |
| Delete (needs the user's yes)    | Ctrl+D       | Secondary                 |
| Delete for good (never use)      | Shift+Delete | Email selected            |
| Archive                          | Backspace    | Secondary, email selected |
| Go to Inbox                      | Ctrl+Shift+I | Anywhere                  |
| Go to Mail                       | Ctrl+1       | Anywhere                  |
| Check names                      | Ctrl+K       | Message window, To box    |
| Address book                     | Ctrl+Shift+B | Anywhere                  |
| Check for new mail               | F9           | Anywhere                  |
