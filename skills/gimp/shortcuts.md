# GIMP shortcuts (Windows, default set, GIMP 3.x)

| Action                        | Shortcut                      | Mode/context       |
| ----------------------------- | ----------------------------- | ------------------ |
| New image                     | Ctrl+N                        | Any                |
| Open                          | Ctrl+O                        | Any                |
| Open as Layers                | Ctrl+Alt+O                    | Any                |
| Save (XCF)                    | Ctrl+S                        | Any                |
| Save As (XCF)                 | Ctrl+Shift+S                  | Any                |
| Export As (JPG, PNG, WebP)    | Ctrl+Shift+E                  | Any                |
| Export again to the same file | Ctrl+E                        | After one export   |
| Close image                   | Ctrl+W                        | Any                |
| Undo                          | Ctrl+Z                        | Any                |
| Redo                          | Ctrl+Y                        | Any                |
| Cut / Copy / Paste            | Ctrl+X / Ctrl+C / Ctrl+V      | Any                |
| Paste as new image            | Ctrl+Shift+V                  | Any                |
| Select all                    | Ctrl+A                        | Any                |
| Select none                   | Ctrl+Shift+A                  | Selection          |
| Invert selection              | Ctrl+I                        | Selection          |
| Toggle Quick Mask             | Shift+Q                       | Selection          |
| Rectangle Select              | R                             | Tools              |
| Ellipse Select                | E                             | Tools              |
| Free Select (lasso)           | F                             | Tools              |
| Fuzzy Select (magic wand)     | U                             | Tools              |
| Select by Color               | Shift+O                       | Tools              |
| Move                          | M                             | Tools              |
| Crop                          | Shift+C                       | Tools              |
| Unified Transform             | Shift+T                       | Tools              |
| Scale                         | Shift+S                       | Tools              |
| Rotate                        | Shift+R                       | Tools              |
| Flip                          | Shift+F                       | Tools              |
| Paintbrush                    | P                             | Tools              |
| Pencil                        | N                             | Tools              |
| Eraser                        | Shift+E                       | Tools              |
| Bucket Fill                   | Shift+B                       | Tools              |
| Gradient                      | G                             | Tools              |
| Clone                         | C                             | Tools              |
| Heal                          | H                             | Tools              |
| Text                          | T                             | Tools              |
| Paths                         | B                             | Tools              |
| Color Picker                  | O                             | Tools              |
| Zoom tool                     | Z                             | Tools              |
| Smaller / larger brush        | [ / ]                         | Painting tools     |
| Default colors                | D                             | Any                |
| Swap colors                   | X                             | Any                |
| Fill with foreground color    | Ctrl+,                        | Layer or selection |
| Fill with background color    | Ctrl+.                        | Layer or selection |
| Zoom in / out                 | + / -                         | Canvas             |
| Zoom to fit image in window   | Ctrl+Shift+J                  | Canvas             |
| Zoom 100 percent              | 1                             | Canvas             |
| Pan                           | Hold Space and move the mouse | Canvas             |
| New layer                     | Ctrl+Shift+N                  | Any                |
| Duplicate layer               | Ctrl+Shift+D                  | Layer              |
| Anchor floating layer         | Ctrl+H                        | Floating selection |
| Select layer above / below    | Page Up / Page Down           | Layers             |
| Layers dialog                 | Ctrl+L                        | Any                |
| Toolbox                       | Ctrl+B                        | Any                |
| Hide or show docks            | Tab                           | Any                |
| Toggle selection outline      | Ctrl+T                        | Canvas             |
| Show rulers                   | Ctrl+Shift+R                  | Canvas             |
| Fullscreen                    | F11                           | Any                |

Scale Image, Canvas Size, Brightness-Contrast and Add Layer Mask have no default shortcut: use Image > Scale Image, Image > Canvas Size, Colors > Brightness-Contrast and Layer > Mask > Add Layer Mask.
