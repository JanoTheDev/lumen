# Windows 11 shortcuts

"Win" is the Windows logo key. Spoken form in lessons: "Windows key and E".

| Action                                     | Shortcut                       | Mode/context                 |
| ------------------------------------------ | ------------------------------ | ---------------------------- |
| Open or close Start                        | Win                            | Anywhere                     |
| Open Settings                              | Win+I                          | Anywhere                     |
| Open File Explorer                         | Win+E                          | Anywhere                     |
| Open Accessibility settings                | Win+U                          | Anywhere                     |
| Show or hide the desktop                   | Win+D                          | Anywhere                     |
| Lock the PC                                | Win+L                          | Anywhere                     |
| Task View (all windows, desktops)          | Win+Tab                        | Anywhere                     |
| Switch between open windows                | Alt+Tab                        | Anywhere                     |
| Close the current window                   | Alt+F4                         | Any window                   |
| Open Task Manager                          | Ctrl+Shift+Esc                 | Anywhere                     |
| Quick Link menu (right-click Start)        | Win+X                          | Anywhere                     |
| Run dialog                                 | Win+R                          | Anywhere                     |
| Search                                     | Win+S                          | Anywhere                     |
| Notification center and calendar           | Win+N                          | Anywhere                     |
| Quick settings (Wi-Fi, volume)             | Win+A                          | Anywhere                     |
| Clipboard history                          | Win+V                          | Text fields                  |
| Emoji and symbols panel                    | Win+.                          | Text fields                  |
| Voice typing                               | Win+H                          | Text fields                  |
| Screenshot of a region (Snipping Tool)     | Win+Shift+S                    | Anywhere                     |
| Screenshot saved to Pictures > Screenshots | Win+PrtScn                     | Anywhere                     |
| Snap window to left half                   | Win+Left                       | Active window                |
| Snap window to right half                  | Win+Right                      | Active window                |
| Maximize window                            | Win+Up                         | Active window                |
| Restore or minimize window                 | Win+Down                       | Active window                |
| Snap layouts menu                          | Win+Z                          | Active window                |
| Move window to other monitor               | Win+Shift+Left                 | Active window, multi-monitor |
| New virtual desktop                        | Win+Ctrl+D                     | Anywhere                     |
| Next / previous virtual desktop            | Win+Ctrl+Right / Win+Ctrl+Left | Anywhere                     |
| Open taskbar app by position               | Win+1 to Win+9                 | Anywhere                     |
| Turn Narrator on or off                    | Win+Ctrl+Enter                 | Anywhere                     |
| Narrator settings                          | Win+Ctrl+N                     | Anywhere                     |
| Magnifier zoom in (starts Magnifier)       | Win+Plus                       | Anywhere                     |
| Magnifier zoom out                         | Win+Minus                      | Magnifier on                 |
| Turn Magnifier off                         | Win+Esc                        | Magnifier on                 |
| Magnifier settings                         | Win+Ctrl+M                     | Anywhere                     |
| On-screen keyboard                         | Win+Ctrl+O                     | Anywhere                     |
| Voice access on or off                     | Win+Ctrl+S                     | Recent Windows 11 builds     |
| Color filters on or off                    | Win+Ctrl+C                     | When enabled in Settings     |
| New folder                                 | Ctrl+Shift+N                   | File Explorer                |
| Rename selected item                       | F2                             | File Explorer                |
| Go up one folder                           | Alt+Up                         | File Explorer                |
| Back / forward                             | Alt+Left / Alt+Right           | File Explorer                |
| Focus the address bar                      | Alt+D                          | File Explorer                |
| Search in folder                           | Ctrl+E                         | File Explorer                |
| Properties of selected item                | Alt+Enter                      | File Explorer                |
| New Explorer tab                           | Ctrl+T                         | File Explorer                |
| Close Explorer tab                         | Ctrl+W                         | File Explorer                |
| Refresh                                    | F5                             | File Explorer                |
| Delete to Recycle Bin                      | Delete                         | File Explorer                |
| Delete permanently (asks first)            | Shift+Delete                   | File Explorer                |
| Select all                                 | Ctrl+A                         | File list, text              |
| Cut / copy / paste                         | Ctrl+X / Ctrl+C / Ctrl+V       | File list, text              |
| Undo                                       | Ctrl+Z                         | File Explorer, text          |
| Open context menu                          | Shift+F10                      | Selected item                |
| Move between panes                         | F6 or Tab                      | File Explorer, Settings      |
| Go back in Settings                        | Alt+Left                       | Settings                     |
