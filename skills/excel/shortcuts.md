# Excel shortcuts (Windows)

| Action                                   | Shortcut                 | Mode/context            |
| ---------------------------------------- | ------------------------ | ----------------------- |
| New workbook                             | Ctrl+N                   | Anywhere                |
| Open                                     | Ctrl+O                   | Anywhere                |
| Save                                     | Ctrl+S                   | Anywhere                |
| Save As                                  | F12                      | Anywhere                |
| Print                                    | Ctrl+P                   | Anywhere                |
| Undo / redo                              | Ctrl+Z / Ctrl+Y          | Anywhere                |
| Show ribbon key tips                     | Alt                      | Anywhere                |
| Show or hide the ribbon                  | Ctrl+F1                  | Anywhere                |
| Move between ribbon, grid and status bar | F6                       | Anywhere                |
| Edit the active cell                     | F2                       | Ready                   |
| Confirm entry and move down              | Enter                    | Enter/Edit              |
| Confirm entry and move right             | Tab                      | Enter/Edit              |
| Cancel entry                             | Esc                      | Enter/Edit              |
| New line inside a cell                   | Alt+Enter                | Enter/Edit              |
| Fill selection with the typed entry      | Ctrl+Enter               | Enter, range selected   |
| Fill down                                | Ctrl+D                   | Range selected          |
| Fill right                               | Ctrl+R                   | Range selected          |
| Flash Fill                               | Ctrl+E                   | Column next to data     |
| AutoSum                                  | Alt+=                    | Ready                   |
| Insert Function dialog                   | Shift+F3                 | Ready                   |
| Toggle absolute reference                | F4                       | Editing a formula       |
| Show formulas instead of results         | Ctrl+`                   | Ready                   |
| Insert current date                      | Ctrl+;                   | Ready or Enter          |
| Insert current time                      | Ctrl+Shift+;             | Ready or Enter          |
| Go to edge of data                       | Ctrl+Arrow               | Ready                   |
| Extend selection to edge of data         | Ctrl+Shift+Arrow         | Ready                   |
| Go to cell A1                            | Ctrl+Home                | Ready                   |
| Go to last used cell                     | Ctrl+End                 | Ready                   |
| Go To dialog                             | Ctrl+G or F5             | Ready                   |
| Select whole column                      | Ctrl+Space               | Ready                   |
| Select whole row                         | Shift+Space              | Ready                   |
| Select all / current region              | Ctrl+A                   | Ready                   |
| Copy / cut / paste                       | Ctrl+C / Ctrl+X / Ctrl+V | Ready                   |
| Paste Special                            | Ctrl+Alt+V               | After copy              |
| Insert cells, rows or columns            | Ctrl+Shift+=             | Selection               |
| Delete cells, rows or columns            | Ctrl+-                   | Selection               |
| Format Cells dialog                      | Ctrl+1                   | Ready                   |
| Bold / italic / underline                | Ctrl+B / Ctrl+I / Ctrl+U | Ready                   |
| Currency format                          | Ctrl+Shift+4             | Ready                   |
| Percent format                           | Ctrl+Shift+5             | Ready                   |
| General number format                    | Ctrl+Shift+`             | Ready                   |
| Create table                             | Ctrl+T                   | Inside data             |
| Turn filter buttons on or off            | Ctrl+Shift+L             | Inside data             |
| Open a filter menu                       | Alt+Down                 | Header cell with filter |
| Embedded chart of the selection          | Alt+F1                   | Data selected           |
| Chart on a new sheet                     | F11                      | Data selected           |
| Find / replace                           | Ctrl+F / Ctrl+H          | Anywhere                |
| Insert hyperlink                         | Ctrl+K                   | Ready                   |
| New worksheet                            | Shift+F11                | Anywhere                |
| Next / previous worksheet                | Ctrl+PgDn / Ctrl+PgUp    | Anywhere                |
| Hide rows / hide columns                 | Ctrl+9 / Ctrl+0          | Selection               |
| Spelling check                           | F7                       | Anywhere                |
| Recalculate all                          | F9                       | Anywhere                |
| Close workbook                           | Ctrl+W                   | Anywhere                |
| Accessibility help                       | Alt+Shift+A              | Anywhere                |
