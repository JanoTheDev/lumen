# VS Code shortcuts (Windows defaults)

Chords like `Ctrl+K Ctrl+O` mean press the first combination, release, then press the second. Any binding can be changed in the Keyboard Shortcuts editor.

| Action                      | Shortcut                      | Mode/context                    |
| --------------------------- | ----------------------------- | ------------------------------- |
| Command Palette             | Ctrl+Shift+P or F1            | Anywhere                        |
| Quick Open, go to file      | Ctrl+P                        | Anywhere                        |
| Open Folder                 | Ctrl+K Ctrl+O                 | Anywhere                        |
| Open File                   | Ctrl+O                        | Anywhere                        |
| New File                    | Ctrl+N                        | Anywhere                        |
| Save                        | Ctrl+S                        | Editor                          |
| Save As                     | Ctrl+Shift+S                  | Editor                          |
| Save All                    | Ctrl+K S                      | Anywhere                        |
| Close editor tab            | Ctrl+W or Ctrl+F4             | Editor                          |
| Reopen closed editor        | Ctrl+Shift+T                  | Anywhere                        |
| Settings                    | Ctrl+,                        | Anywhere                        |
| Keyboard Shortcuts editor   | Ctrl+K Ctrl+S                 | Anywhere                        |
| New window                  | Ctrl+Shift+N                  | Anywhere                        |
| Show Explorer               | Ctrl+Shift+E                  | Anywhere                        |
| Show Search (find in files) | Ctrl+Shift+F                  | Anywhere                        |
| Replace in files            | Ctrl+Shift+H                  | Anywhere                        |
| Show Source Control         | Ctrl+Shift+G                  | Anywhere                        |
| Show Run and Debug          | Ctrl+Shift+D                  | Anywhere                        |
| Show Extensions             | Ctrl+Shift+X                  | Anywhere                        |
| Toggle Primary Side Bar     | Ctrl+B                        | Anywhere                        |
| Show Problems panel         | Ctrl+Shift+M                  | Anywhere                        |
| Show Output panel           | Ctrl+Shift+U                  | Anywhere                        |
| Toggle integrated terminal  | Ctrl+`                        | Anywhere                        |
| New terminal                | Ctrl+Shift+`                  | Anywhere                        |
| Commit staged changes       | Ctrl+Enter                    | Source Control message box      |
| Find                        | Ctrl+F                        | Editor                          |
| Replace                     | Ctrl+H                        | Editor                          |
| Go to line                  | Ctrl+G                        | Editor                          |
| Go to symbol in file        | Ctrl+Shift+O                  | Editor                          |
| Go to Definition            | F12                           | Editor, cursor on a symbol      |
| Peek Definition             | Alt+F12                       | Editor                          |
| Show References             | Shift+F12                     | Editor                          |
| Rename Symbol               | F2                            | Editor                          |
| Quick Fix                   | Ctrl+.                        | Editor, on a squiggle           |
| Trigger suggestion          | Ctrl+Space                    | Editor                          |
| Format Document             | Shift+Alt+F                   | Editor                          |
| Toggle line comment         | Ctrl+/                        | Editor                          |
| Move line up or down        | Alt+Up / Alt+Down             | Editor                          |
| Copy line up or down        | Shift+Alt+Up / Shift+Alt+Down | Editor                          |
| Delete line                 | Ctrl+Shift+K                  | Editor                          |
| Add next match to selection | Ctrl+D                        | Editor                          |
| Select all matches          | Ctrl+Shift+L                  | Editor                          |
| Add cursor above or below   | Ctrl+Alt+Up / Ctrl+Alt+Down   | Editor                          |
| Add cursor at click         | Alt+Click                     | Editor                          |
| Undo last cursor            | Ctrl+U                        | Editor                          |
| Toggle word wrap            | Alt+Z                         | Editor                          |
| Split editor                | Ctrl+\                        | Editor                          |
| Focus editor group 1, 2, 3  | Ctrl+1 / Ctrl+2 / Ctrl+3      | Anywhere                        |
| Next or previous error      | F8 / Shift+F8                 | Editor                          |
| Start or continue debugging | F5                            | Anywhere                        |
| Stop debugging              | Shift+F5                      | Debugging                       |
| Toggle breakpoint           | F9                            | Editor                          |
| Step over / into / out      | F10 / F11 / Shift+F11         | Debugging                       |
| Zen Mode                    | Ctrl+K Z                      | Anywhere (Escape twice to exit) |
| Zoom in or out              | Ctrl+= / Ctrl+-               | Anywhere                        |
| Accessibility Help          | Alt+F1                        | Focused part                    |
| Accessible View             | Alt+F2                        | Hover, chat, notification       |
| Focus next or previous part | F6 / Shift+F6                 | Anywhere                        |
| Toggle Tab moves focus      | Ctrl+M                        | Editor                          |
