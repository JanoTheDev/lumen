# Zoom keys

| App                         | Zoom in                         | Reset                         |
| --------------------------- | ------------------------------- | ----------------------------- |
| Edge, Chrome, Firefox       | Ctrl+Plus                       | Ctrl+0                        |
| Word, Excel, PowerPoint     | Ctrl+mouse wheel, or View, Zoom | View, 100%                    |
| Outlook reading pane        | Ctrl+mouse wheel                | the zoom slider at the bottom |
| Visual Studio Code          | Ctrl+Plus                       | Ctrl+0                        |
| File Explorer               | Ctrl+Plus (icon size)           | Ctrl+Minus                    |
| Windows Magnifier (any app) | Windows+Plus                    | Windows+Esc                   |
