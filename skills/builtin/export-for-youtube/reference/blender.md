# Blender

1. Properties editor, Output tab: Resolution 1920 x 1080 (1080p) or 3840 x 2160 (4k), 100 %.
2. Output path: the Videos folder plus the project name. File Format: FFmpeg Video.
3. Encoding: Container MPEG-4, Video Codec H.264, Output Quality "High quality"; Audio Codec AAC.
4. Render, then Render Animation (Ctrl+F12).
