# Figma shortcuts (Windows, Figma Design)

| Action                             | Shortcut                | Mode/context                |
| ---------------------------------- | ----------------------- | --------------------------- |
| Move tool                          | V                       | Canvas                      |
| Scale tool                         | K                       | Canvas                      |
| Frame tool                         | F or A                  | Canvas                      |
| Section tool                       | Shift+S                 | Canvas                      |
| Rectangle                          | R                       | Canvas                      |
| Ellipse                            | O                       | Canvas                      |
| Line                               | L                       | Canvas                      |
| Arrow                              | Shift+L                 | Canvas                      |
| Pen                                | P                       | Canvas                      |
| Pencil                             | Shift+P                 | Canvas                      |
| Text                               | T                       | Canvas                      |
| Hand tool                          | H, or hold Space        | Canvas                      |
| Comment                            | C                       | Canvas                      |
| Place image                        | Ctrl+Shift+K            | Canvas                      |
| Show keyboard shortcuts            | Ctrl+Shift+?            | Any                         |
| Quick actions / search             | Ctrl+/                  | Any                         |
| Undo                               | Ctrl+Z                  | Any                         |
| Redo                               | Ctrl+Shift+Z            | Any                         |
| Copy / Paste                       | Ctrl+C / Ctrl+V         | Selection                   |
| Duplicate                          | Ctrl+D                  | Selection                   |
| Delete                             | Delete or Backspace     | Selection                   |
| Rename layer                       | Ctrl+R                  | Selection                   |
| Group selection                    | Ctrl+G                  | Selection                   |
| Ungroup                            | Ctrl+Shift+G            | Group                       |
| Frame selection                    | Ctrl+Alt+G              | Selection                   |
| Add auto layout                    | Shift+A                 | Selection                   |
| Remove auto layout                 | Alt+Shift+A             | Auto layout frame           |
| Create component                   | Ctrl+Alt+K              | Selection                   |
| Detach instance                    | Ctrl+Alt+B              | Instance                    |
| Show / hide selection              | Ctrl+Shift+H            | Selection                   |
| Lock / unlock selection            | Ctrl+Shift+L            | Selection                   |
| Select all                         | Ctrl+A                  | Canvas                      |
| Select children                    | Enter                   | Frame or group              |
| Select parent                      | Shift+Enter             | Layer                       |
| Bring forward / send backward      | Ctrl+] / Ctrl+[         | Selection                   |
| Align left / right                 | Alt+A / Alt+D           | Selection                   |
| Align top / bottom                 | Alt+W / Alt+S           | Selection                   |
| Align centers                      | Alt+H / Alt+V           | Selection                   |
| Zoom in / out                      | Ctrl+= / Ctrl+-         | Canvas                      |
| Zoom to 100 percent                | Shift+0                 | Canvas                      |
| Zoom to fit all                    | Shift+1                 | Canvas                      |
| Zoom to selection                  | Shift+2                 | Selection                   |
| Previous / next page               | Page Up / Page Down     | Canvas                      |
| Switch Design and Prototype tabs   | Shift+E                 | Any                         |
| Preview prototype in the editor    | Shift+Space             | Prototype                   |
| Present prototype                  | Ctrl+Alt+Enter          | Any                         |
| Export                             | Ctrl+Shift+E            | Layers with export settings |
| Show / hide UI panels              | Ctrl+\                  | Any                         |
| Toggle Dev Mode                    | Shift+D                 | Any                         |
| Toggle rulers                      | Shift+R                 | Canvas                      |
| Pick color (eyedropper)            | I                       | Canvas                      |
| Copy properties / paste properties | Ctrl+Alt+C / Ctrl+Alt+V | Selection                   |
