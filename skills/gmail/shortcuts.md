# Gmail shortcuts

From Google's Gmail help, checked 2026-10-01. Single-key shortcuts work only after Settings > See all settings > Keyboard shortcuts on. Ctrl+Enter works without that setting.

| Action                           | Shortcut     | Mode/context               |
| -------------------------------- | ------------ | -------------------------- |
| Compose                          | c            | Shortcuts on               |
| Search mail                      | /            | Shortcuts on               |
| Go to Inbox                      | g then i     | Shortcuts on               |
| Open conversation                | o or Enter   | Shortcuts on, row selected |
| Back to the message list         | u            | Shortcuts on, email open   |
| Newer conversation               | k            | Shortcuts on               |
| Older conversation               | j            | Shortcuts on               |
| Select conversation              | x            | Shortcuts on               |
| Reply                            | r            | Shortcuts on, email open   |
| Reply all                        | a            | Shortcuts on, email open   |
| Forward                          | f            | Shortcuts on, email open   |
| Archive                          | e            | Shortcuts on               |
| Delete (needs the user's yes)    | #            | Shortcuts on               |
| Report spam (needs a yes)        | !            | Shortcuts on               |
| Mark as read                     | Shift+i      | Shortcuts on               |
| Mark as unread                   | Shift+u      | Shortcuts on               |
| Undo last action                 | z            | Shortcuts on               |
| Add Cc recipients                | Ctrl+Shift+c | Compose window             |
| Add Bcc recipients               | Ctrl+Shift+b | Compose window             |
| Send (only after the user's yes) | Ctrl+Enter   | Compose window             |
| Keyboard shortcut help           | Shift+?      | Shortcuts on               |
